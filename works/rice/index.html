优先级罗盘

RICE Compass — 把「都很重要」换成一份能吵架的排序。

需求池里十几条都写着「重要 / 紧急」，排期会开成表态大会。我需要的不是更复杂的评估体系， 而是一张五分钟能填完、当场能改、改完能吵的表：把直觉拆成覆盖面、影响力、信心和成本四个数， 算出来的顺序不一定对，但至少让分歧落在具体那一格上。

所以它刻意做得很轻：没有登录、没有后端、数据只存在你自己的浏览器里， 刷新不丢、可以调权重、可以一键导出 Markdown 直接贴进 PRD 或周报。

Design Notes · 设计思路

工具的价值不在算分，
在于把分歧摊开

The score is not the point.

01

Impact 用档位，不给自由输入

0.25 / 0.5 / 1 / 2 / 3 五档，逼着大家在「大概多大」上先达成一致，而不是在小数点上互相说服。

02

Confidence 是刹车，不是修饰

低于 60% 的需求会被单独点出来：它需要的是一次小实验或一次数据核对，而不是一个排期位置。

03

权重可调，是为了做敏感性分析

把 Effort 惩罚拉到 1.5 再看排名有没有翻转——排名稳定的，才值得写进季度计划。

04

结论必须能被搬走

导出 Markdown 直接贴进 PRD / 周报，让一次会议的判断留下痕迹，下次复盘还能被质疑。
